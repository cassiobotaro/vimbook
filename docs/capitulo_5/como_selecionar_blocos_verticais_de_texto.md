Pressione `Ctrl-V` e use as letras h,l,k,j como setas de direção até
finalizar podendo guardar a seleção em um registrador que vai de
'a' a 'z' exemplo:
```text
"ay
```
Em modo normal você pode fazer assim para guardar um parágrafo inteiro
em um registrador
```text
"ayip
```
O comando acima quer dizer

| Comando | Descrição |
|---------|-----------|
| `"a` | para o registrador `a' |
| `y` | copie |
| `ip` | o parágrafo atual (*inner paragraph*) |
